# Phantom Share

[![Phantom Share — Connect. Drop. Share.](banner.png)](https://phantomshare.app/)

**[Launch Phantom Share ↗](https://phantomshare.app/)** · [All demos](../README.md)

Direct, encrypted file sharing between devices. No account. No cloud storage.

## Try it

1. Open Phantom Share on two devices. On the first, choose **Connect → Create**.
2. On the other, choose **Connect → Join** and scan the QR code or enter the invitation code or link.
3. Select or drop a file. Received files appear on the other device; choose **Save** in a browser.

An invitation lasts four minutes and admits one device. Create a fresh invitation for each additional device.

## What it shows

- Device pairing through codes, links and QR invitations.
- Peer-to-peer file distribution, with recipient selection.
- Device membership, removal and session controls.
- An Android app using the same web interface, with automatic saving to Downloads.
- Android-hosted local sharing: the host serves a PIN join page to another device on the LAN.

The website, Android interface and locally served page come from the Phantom Share application project. This showcase links to the current website rather than maintaining another copy of the app. Installed Android apps require an updated build to receive changes.
