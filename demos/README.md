# Built with Phantom

Real applications powered by Phantom SDK. Open a demo and try it across your devices.

## Phantom Share

[![Phantom Share — Connect. Drop. Share.](phantom-share/banner.png)](https://phantomshare.app/)

Share files directly between devices. Connect with a code, link or QR, choose your files, and send. No account. No cloud storage.

**[Open Phantom Share ↗](https://phantomshare.app/)** · [About the demo](phantom-share/README.md)

Supports recipient selection, device removal, and an Android-hosted LAN mode for local sharing.

## Shared canvas

Draw together across connected browsers over peer data channels.

**[Open shared canvas ↗](https://phantom-canvas.pages.dev/)** · [Source and setup](shared-canvas/README.md)

Create a room on one device and scan its QR code on another. This is the existing SDK canvas example; a branded Canvas showcase will be added when that application is ready.
